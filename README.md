# 函迹 · FuncTrace —— 设计说明（评分 / 误差 / 函数 / 难度）

> 版本：v1.0.2（已完成） · 最后更新：2026-08-26
> 本文件是游戏核心设计规范的**唯一权威说明**。任何涉及评分标准、误差、函数族、难度、时间档位、对战模式数值的改动，都必须同步更新本文件（见末尾「维护约定」）。
> 与 `index.html` 同目录，分离版运行时可直接访问 `/instruction.md` 查看。

---

## 1. 游戏目标

系统随机给出一条函数曲线（开局横幅显示表达式，坐标系初始为空白），玩家在坐标系上放置有限个点，
使这些点尽量贴近真实曲线。提交（或时间到）后，按每个点与曲线的**最近距离**逐点打分，并叠加时间奖励，得出本局总分（满分 100）。

- 开局：顶部横幅显示函数表达式，约停留后进入放点阶段。
- 判定后：坐标系展示真实曲线，停留约 1 秒后再弹出结果。

---

## 2. 难度（决定函数族与点数）

难度只决定**函数族范围**和**点数 quota**，不决定时间（时间由第 3 节档位决定）。

| 难度 key | 名称 | 函数族 | 点数 quota |
|----------|------|--------|-----------|
| easy | 入门 | 一次函数 linear | 2 |
| normal | 进阶 | 二次 quad、绝对值 abs | 3 |
| hard | 专家 | 三次 cubic、正弦 sine、指数 exp | 4 |
| mix | 混合 | 全部六种 | 4 |

> 注：后端 `server.js` 的 `LEVELS.time`（20/30/40/45）为遗留字段，正式开局已被前端档位时间覆盖，不再生效。

---

## 3. 时间档位（决定时限）

点击难度卡片（主页或游戏内顶栏）后弹出时间选择弹窗，由长到短四档：

| 档位 key | 名称 | 时限（秒） |
|----------|------|-----------|
| rookie | 萌新 | 60 |
| skilled | 熟手 | 40 |
| master | 高手 | 25 |
| challenge | 挑战 | 15 |

- 点数仍由难度决定（第 2 节），时间档位与点数**相互独立**。
- 若在对局中点顶栏难度换档，弹窗期间**暂停当前计时**，取消则恢复，避免误超时。
- HUD 难度行显示「难度 · 档位」，例如 `入门 · 萌新`。

## 4. 坐标系与视图

- 横坐标固定 `x ∈ [-10, 10]`。
- 纵坐标 `y` 根据函数自适应：`ymin = max(mn - pad, -14)`，`ymax = min(mx + pad, 14)`，
  其中 `mn/mx` 为函数在 `[-10,10]` 上的最小/最大值，`pad = max(span*0.12, 0.6)`，`span = mx - mn`。
- 生成约束（`genFor`）：最多尝试 80 次，要求 `span ∈ [1.2, 16]` 且 `mn ≥ -13.5` 且 `mx ≤ 13.5`；
  否则回退为一次函数 linear。
- 坐标系单位：每格 = 1 个单位，x 轴共 20 格。

## 5. 函数族定义与生成参数

所有随机参数范围如下（两版实现必须一致）：

| 族 | 公式 `f(x)` | 随机参数范围 |
|----|------------|-------------|
| linear 一次 | `k·x + b` | `k = ±rand(0.15, 0.8)`，`b = rand(-4, 4)` |
| quad 二次 | `a·(x−h)² + k` | `h = rand(-6, 6)`，`a = ±rand(0.5, 1.2)·(8/maxE)`，`k = rand(-6, 6)`，`maxE = max((10−h)², (10+h)²)` |
| abs 绝对值 | `a·|x−h| + k` | `h = rand(-5, 5)`，`a = ±rand(0.6, 1.4)·(8/maxE)`，`k = rand(-6, 6)`，`maxE = max(|10−h|, |10+h|)` |
| cubic 三次 | `a·(x−h)³ + k` | `h = rand(-2, 2)`，`a = ±rand(0.6, 1.3)·(9/maxE)`，`k = rand(-5, 5)`，`maxE = max(|10−h|³, |10+h|³)` |
| sine 正弦 | `A·sin(B·x + C) + D` | `A = rand(1.5, 3.5)`，`B = rand(0.35, 1)`，`C = rand(0, 2π)`，`D = rand(-3, 3)` |
| exp 指数 | `a·e^(b·x) + d` | `a = ±rand(1, 3)`，`b = ±rand(0.08, 0.2)`，`d = rand(-4, 4)` |

- 配色（曲线颜色）固定映射：`linear #2563eb`、`quad #7c3aed`、`abs #0891b2`、`cubic #db2777`、`sine #16a34a`、`exp #ea580c`。
- 数值格式化 `fmt(v)`：普通值保留两位小数；当 `|v| < 0.01` 且 `v ≠ 0` 时保留四位小数，避免三次函数等系数过小时被显示成 `0`（例如 `0.0045(x+1)³` 不再显示为 `0(x+1)³`）。

## 6. 评分标准（核心）

### 6.1 关键常量

| 常量 | 值 | 含义 |
|------|----|------|
| `R` | 4 | 容差半径（单位）。点到曲线距离 ≥ R 时该点得 0 分。 |
| `GAMMA` | 2 | 衰减指数。>1 时越偏离曲线得分下降越快（更严格）。 |
| `M` | `100 / quota` | 单点满分（quota 为第 2 节点数）。 |
| `bonusMax` | 10 | 时间奖励上限（速度奖励）。 |

### 6.2 单点得分

对玩家放置的每个点 `p(x, y)`：

1. **最近距离 `d`**：在真实曲线上按**当前视图范围**均匀采样（`x = xmin + range·i/n`，`n = max(601, ⌈range/0.02⌉)`，采样密度自适应，范围越大点越密），
   取与点 `p` 的欧氏距离最小者，即 `d = min √( (x−p.x)² + (y−p.y)² )`。
2. **垂直误差 `vert`**：`vert = |f(p.x) − p.y|`（结果弹窗中一并展示）。
3. **单点得分**：
   ```
   score_point = round( pow( clamp(1 − d/R, 0, 1), GAMMA ) × M × 10 ) / 10
   ```
   - `d = 0`（精准命中）→ 该点满分 `M`。
   - `d ≥ R`（偏差 ≥ 4 单位）→ 0 分。
   - 单点满分上限 `max = round(M × 10) / 10`。

### 6.3 单点得分对照表（偏差 d → 单点得分占比）

| 偏差 d（单位） | 单点得分占比 | 备注 |
|--------|----------|------|
| 0 | 100% | 命中满分 |
| 0.5 | 76.6% | |
| 1 | 56.3% | （旧线性 75%） |
| 1.5 | 39.1% | |
| 2 | 25.0% | （旧线性 50%） |
| 2.5 | 14.1% | |
| 3 | 6.3% | （旧线性 25%） |
| 3.5 | 1.6% | |
| ≥4 | 0% | 超出容差 |

> 平方衰减（`GAMMA=2`）使中等偏差大幅掉分，而精准命中不受影响——这是「判定更严格」的实现方式。

### 6.4 本局总分

```
sum   = Σ score_point                      （所有玩家点的单点得分之和）
ratio = clamp(timeLeft / timeTotal, 0, 1)  （timeTotal 为本局所选档位时限）
bonus = round(10 × ratio × 10) / 10        （速度奖励，最多 +10 分）
score = round( min(100, sum + bonus) × 10 ) / 10
```

- `timeLeft`：提交时剩余时间（秒）；超时提交时 `timeLeft = 0`，`bonus = 0`。
- 总分封顶 100。

### 6.5 评级（rating）

| 分数 | 等级 | CSS class |
|------|------|-----------|
| ≥ 99.5 | 完美 | b-perfect |
| ≥ 85 | 优秀 | b-good |
| ≥ 70 | 良好 | b-ok |
| ≥ 50 | 及格 | b-far |
| < 50 | 不及格 | b-out |

- 结果弹窗「完美」徽章 `rPerfect` 在 `score ≥ 99.5` 时显示。

### 6.6 结果弹窗每点徽章（按最近距离 d）

| 距离 d（单位） | 文案 | class |
|----------|------|-------|
| < 0.25 | 完美 | b-perfect |
| < 0.75 | 优秀 | b-good |
| < 1.5 | 不错 | b-ok |
| < 2.6 | 偏差 | b-far |
| 其他 | 太远 | b-out |

## 7. 误差 / 距离计算说明

- **距离单位**：坐标系单位（每格 1）。默认视图 `x ∈ [-10,10]` 全屏，玩家点击精度受缩放影响；
  未缩放时粗略点击误差约 0.5–2 单位，缩放后可更精准。
- **最近距离 d**：基于曲线离散采样（默认 ≥601 点，`n = max(601, ⌈range/0.02⌉)`，采样范围跟随评估时的视图 `view`，默认 ±10）。非解析法线距离，但采样足够密，误差可忽略。**注意**：调试模式支持滚轮缩放，若点落在默认 ±10 之外，评估必须传入当前视图，否则最近点会被钳制在采样边界（曾因此出现"最近点在别处"的 bug）。
- **垂直误差 vert**：仅用于结果展示与「偏差」直观提示，不参与计分。
- 容差半径 `R` 保持不变（=4）是为了不惩罚正常手稳玩家；严格化完全由 `GAMMA=2` 的平方衰减实现。

## 8. 调试模式

- 快捷键 **Ctrl + Shift + D**，**仅主页（homeView 可见时）** 可开启。
- 功能：表达式输入（`preprocessExpr`/`makeFn` 解析，支持 `sin/cos/tan/abs/exp/sqrt/log/⌊⌋/round`、`^` 幂、`|x|` 绝对值、`PI/E/e` 常数）、图像上放置点、缩放、记录增删改查、导入导出。
- 调试评分（`evalDebug`）：单点公式与正式一致（`R=4, GAMMA=2`，`M = 100/点数`），
  总分 `= clamp(sum, 0, 100)`（**无时间奖励**，因调试不计正式分）。

## 11. 点之趋安模式（Axis Dodge）

在「设置」左侧的「点之趋安」标签页，与「点之描函」（函数值点游戏，标签为「点之描函」）并列，均为品牌「函迹 · FuncTrace」下的子游戏。两个标签页顶部均含标题 + 玩法介绍块 `.axis-intro`（点之描函「Function Trace」/ 点之趋安「Axis Dodge」）；点之趋安介绍文案面向玩家，不使用 `res`、`[res−4,res+4]` 等术语。

### 11.1 玩法
- 进入后顶部显示一道算式，玩家心算答案（**危险区不显示在数轴上**）。
- 玩家用 ← → 方向键移动数轴上的「你」，倒计时结束前确保自己不在「答案附近的一段危险区」内。
- 倒计时结束：落在危险区 → 被淘汰（记录坚持轮数）；安全 → 休息 3s 进入下一轮（新算式、**位置保留**）。

### 11.2 难度（4 档，决定算式复杂度与等待时间）
| 难度 | 算式复杂度 | 等待时间 | 休息 |
|------|------------|----------|------|
| 入门 | 加减法 | 6s | 3s |
| 进阶 | 加减乘 | 5s | 3s |
| 专家 | 括号乘除、开方 √、立方根 ∛、对数 log₂ | 4s | 3s |
| 混合 | 全部题型综合 | 4s | 3s |

### 11.3 算式与数轴
- 数轴范围 `[-8, 8]`（宽 16），刻度每 2 单位。
- 算式结果 `res` 强制 ∈ `[-8, 8]`（与数轴同范围）；危险区 `[res − r, res + r]` 长度 ≤ 4 < 轴长 16，玩家总能找到安全位置。
- 算式生成器 `genAxisExpr(levelKey)`：入门 `a ± b`；进阶 `a×b ± c` / `a + b×c`；专家含 `(a+b)×c`、`a×b − c`、`√(a) ± b`（a 为 2\~30 混合取值，非完全平方时结果为小数、玩家近似估算即可安全）、`∛(a) ± b`（a 为 2\~30）、`log₂(a) ± b`（a 为 2\~32 混合取值、不全是 2 的次幂，非整结果玩家近似估算即可安全；专家 6 选 1，log 权重 2/6）；混合再含 `a × √(b) − c`（√b 为整数）、`∛(a) ± b`，10 种题型随机，结果不满足范围则重试（最多 300 次）。题型数字范围已按轴宽等比缩小（约 1/3），保持相对难度。**负数结果**：生成结果后约 45% 概率整体取负（`res` 取相反数，公式显示为 `−(... ) = ?`），保证正负结果大致均衡。

### 11.4 移动与判定
- 画布：`720×300`，CSS `aspect-ratio:720/300; height:auto` 保证宽高比，任意屏宽不形变。
- 开局流程：点难度卡片 → 弹出设置浮窗 `#axisSetupDlg`（标题「点之趋安 · 难度」，正文显示难度描述与等待时间；内含**规则开关**（避开险区 / 落入靶心）+ 半径滑块 + 「开始 / 取消」按钮）→ 选规则、拖好半径点「开始」进入；`startAxis` 开局随机生成玩家位置。HUD 只读显示当前规则（`axisRuleTag`）。
- 移动：← → 每 **15ms 移动 0.1 单位**（≈6.7 单位/秒，可长按连续），`clamp` 到 `[-8, 8]`，实时显示「你的位置 x」。**每轮结束后保留当前位置**（不重置），下一轮直接从原地继续躲。
- 危险区半径：滑块 `#axisRadius` 范围 **1–2**（步长 0.05，精度两位小数，默认 1，实时显示 `axisRadiusVal`），开局确定后锁定为 `roundRadius`（HUD 只读显示 `axisRoundRadius`），整局不变；危险区 = `[res − roundRadius, res + roundRadius]`。
- 判定（按开局所选规则 `rule`）：**避开险区**（默认）——`|playerX − res| ≤ roundRadius` 命中淘汰；**落入靶心**——规则反转，`|playerX − res| > roundRadius`（未落入危险区）命中淘汰。
- 评分（仅**落入靶心**模式）：每轮安全后按落点与靶心的接近程度计分 `scoreRound = max(0, round(100 × (1 − |playerX − res| / roundRadius)))`（正中靶心 100 分、靶缘 0 分）；本局 `avgScore` = 安全轮次平均分（0-100），HUD 实时显示，结果弹窗与历史记录同步展示；避开险区模式无评分。
- 激光与印记颜色：**避开险区 = 红色**（危险区语义）；**落入靶心 = 绿色**（目标区语义）；历史迷你数轴按记录 `rule` 同色。
- 激光与印记（每次倒计时结束触发）：
  - 立刻在危险区发射 280ms 红色强光柱：垂直渐变，轴线 `midY` 处最亮（alpha 1.0，中心 4px 白色亮线 + 轴线处 6px 红粗线 + 两端红短线），上下端衰减到 0.2；
  - 留下「中间深两边浅」的红色渐变印记（横向 `linear-gradient`，端点 `0` → 中心 `0.6` → 端点 `0`），上覆 3px 红色主线；
  - 下一轮 `axisNextRound` 时清除印记与激光计时（`marks=null`、`laserUntil=0`）。

### 11.5 记录
- 淘汰时写入历史（分离版 `POST /api/history`；单文件版 `localStorage.setItem(HISTORY_KEY,...)`），entry 含 `mode:'axis'`、`score = 坚持轮数`、`rounds`、`formula`、`res`、`radius`（本轮锁定的危险区半径）、`rule`（'avoid' 避开险区 / 'enter' 落入靶心）、`avgScore`（落入靶心模式的安全轮平均分，其余模式为 null）、`dangerLow/High = res ± radius`、`playerPos`、`survived`（`false`=被淘汰 / `true`=主动退出）、`roundsData[]`（**每轮详细记录**：每轮 `{round, formula, res, playerX, dangerLow, dangerHigh, hit}`，在 `axisResolveRound` 判定时入栈，用于详情复盘）。
- **主动退出也保存**：`exitAxis`（「✕ 退出本局」或切走标签）时若已产生至少一轮判定记录，同样写入历史（`survived:true`，坚持轮数 = 安全轮数），toast 提示「已保存本局进度」；历史卡片徽章区分「被淘汰 / 主动退出」，详情弹窗结果行颜色区分（红=淘汰 / 绿=退出）。
- 因后端 `validateEntry`/`normalizeList` 要求 `ts` 与 `score` 为数字，axis 记录以「坚持轮数」作为 `score` 通过校验；`roundsData` 是额外字段，不影响校验。
- 主页「历史记录」渲染按 `mode` 分支：axis 显示「坚持 N 轮 · 难度 · 公式」；统计（平均分 / 最高分 / 满分次数）仅统计 `mode!=='axis'` 的原函数游戏记录，避免污染。
- 单文件版 `functrace.html` 同步实现点之趋安：记录写入 localStorage（`HISTORY_KEY`），历史渲染同样按 `mode` 分支。

### 11.6 历史统计 chip
- 主页「历史记录」顶部 chip 顺序：**场次 / 平均分 / 最高分 / 满分次数 / 趋安最佳**（第 5 个）。
- 「趋安最佳」= 所有 `mode==='axis'` 记录中 `rounds`（或 `score`）的最大值，即「点之趋安最高坚持轮数」。无 axis 记录时显示 `0`。仅统计 axis 记录，与函数值点统计互不干扰。

### 11.7 历史详情（点之趋安）
- 在历史列表点击轴游戏的「详情」按钮，弹窗内展示：
  - **本局摘要**（去术语）：本题算式 / **答案** / **危险区**（用 `dangerLow/High`，不再显示 `res` 或固定 `[res−4,res+4]`）/ 你的位置 / 结果。
  - **每轮详情**（若有 `roundsData`）：列表展示本局每一轮的「#轮号 + 式子 + 命中/安全徽章 + 玩家位置 + 危险区」，下方配 **迷你数轴**（`<canvas class="axis-r-mini" width="320" height="50">`，由 `drawAxisMini` 渲染轴线 + 红色危险区 + 玩家蓝点，深色主题自适应）。弹窗可滚动（`max-height:88vh`）便于复盘多轮。
- `roundsData` 缺失（v1.0 之前的旧记录）时仅显示本局摘要，不报错。

## 12. 点之对战模式（Function Battle）

在「设置」左侧的「点之对战」标签页，与「点之描函」「点之趋安」并列，为品牌「函迹 · FuncTrace」下的第三个子游戏。纯前端实时玩法（两版同构），世界有边界、相机跟随，玩家用算式武器攻击怪物，撑得越久记录越亮眼。

### 12.1 玩法与操作
- 开放 2D 世界 **2400×1800** 有边界 + 相机跟随；逻辑视口 **880×560**，高清渲染（buffer = 880×dpr，`dpr = clamp(2, devicePixelRatio, 3)`，`setTransform(dpr,...)` 按逻辑坐标绘制）。
- 玩家始终**面向鼠标**（mousemove 映射世界坐标，含全屏 letterbox 黑边偏移修正）；**左键射击**，**空格暂停**（暂停时画面冻结显示遮罩），**E 放墙**，**滚轮切武器仅全屏**（非全屏 1\~4 数字键随时可用）。
- **4 把武器**（消耗能量）：`-1` 减一（耗 1）· `√` 开方（耗 3，目标 <0 无效）· `÷2` 折半（耗 2）· `×(-1)` 取反（免费）。
- **怪物**：血量**不可见**、初始等于它的式子（预设集合，式子不可变而血量可变），`|val| ≤ 0.005` 死亡；`val > 0` 红色、`val < 0` 蓝色；头顶显示式子文字。
- **怪物移动（不全图追踪）**：距玩家 `< 430px` 以 78 速追击（带 ±24 随机抖动）；`≥ 430px` 随机游荡（40 速，每 2\~5s 随机换向）。近身每 **1.4s** 攻击一次 **-5** 血。
- **血包**：每 10 秒随机刷 1 个（+10\~15 血，场上最多 2 个）；BOSS 击破额外掉落分散血包。
- **能量系统**：按模式上限（见 12.2）；射击按武器消耗；能量 `≤ 5` 进入回能，5 秒后回满；HUD 以浅蓝进度条显示（普通栏与全屏 HUD 双份）。
- **墙**：E 在面朝方向放墙，耗 5 能量、冷却 10s、持续 5s、最多 3 面，阻挡玩家与实体。
- **视野外指向标**：小怪/BOSS 中心出界超过自身半径时，屏幕边缘显示细长三角箭头（长 14 × 宽 7）指向其方位——**红**=正数怪 · **蓝**=负数怪 · **紫**=BOSS（半透明底圆 + 箭头，边距 26px 与屏幕边界求交）。
- **全屏**：⛶ 按钮对 `#battleStage` 请求全屏；全屏态武器快捷栏沉底、顶部胶囊 HUD（❤血量/血条+能量条/时长/击杀）、`user-select:none` 禁选文字；阵亡/退出先退出全屏再弹结算。
- 结算弹窗 `#battleResult`（坚持时长 + 击杀数）；离开对战标签自动退出（不保存中途退出），主动点「✕ 退出本局」保存记录。

### 12.2 模式（4 种，`BT.mode`）

| 模式 key | 名称 | 小怪 | BOSS | 能量上限 |
|----------|------|------|------|----------|
| classic | 经典模式 | 开局 5 只 + 每 4s 刷 1 只（上限 12） | 每 300s 一个 | 100 |
| boss | BOSS 模式 | 无小怪 | 每 60s 一个（**开局第 0s 即来**） | 250 |
| nohurt | 无伤挑战 | 同经典（开局 5 只 + 每 4s） | 每 300s 一个 | 100 |
| custom | 自定义模式 | 按配置 | 按配置 | 按配置 |

- 开局默认经典模式；模式卡片 `#battleModes`（`.bm`）点击切换，选中高亮。
- **自定义模式**：点击卡片弹出设置弹窗 `#customDlg`，5 个滑块（含实时数值预览），「开始游戏」写入 `BT.custom` 后开局，「取消」回到经典模式：
  - 血包生成频率 5\~30s（默认 10）· 小怪生成频率 1\~15s（默认 4）· BOSS 生成频率 30\~600s（默认 300）· 生命上限 1\~500（默认 100）· 能量上限 50\~500（默认 250）。
- **动态配置**：`btReset` 按模式计算 `BT.hpMax / maxE / packInt / spawnInt / bossInt`（custom 读 `BT.custom`，nohurt 覆盖 `hpMax=1`，其余取默认常量）；游戏循环与 HUD 全部引用动态值，boss 模式固定 60s。
- 无伤挑战玩家血量 = 1（一血到底），血条按 `hp/hpMax` 归一化显示满条，被击中即阵亡。

### 12.3 BOSS 机制
- 场上同时最多 1 个；血量 **500\~1500**（`hpMax` 字段，血条按 `val/hpMax` 归一化），**血量可见**（头顶数值 + 血条）；紫色大怪 + 金色王冠。
- 追击较慢（52 速，520px 内追、外游荡），攻击 -8（`BT_BOSS_DMG`）；武器同样可运算其血量，`|val| ≤ 0.005` 死亡。
- 击破：掉 **5\~10 个**血包（环形散布：角度均匀 + 随机抖动，半径 45\~95px），toast + 警报音；击杀计入 kills。

### 12.4 关键常量

| 常量 | 值 | 含义 |
|------|----|------|
| `BT_DEAD` | 0.005 | 死亡判定精度（`\|val\|≤0.005`） |
| `BT_HP` | 100 | 玩家默认血量上限（nohurt 覆盖为 1） |
| `BT_DMG` / `BT_BOSS_DMG` | 5 / 8 | 小怪 / BOSS 每次攻击伤害 |
| `BT_ATK_CD` / `BT_ATK_RANGE` | 1.4s / 80px | 攻击间隔 / 攻击距离 |
| `BT_SPAWN_INT` / `BT_MAX_M` | 4s / 12 | 小怪刷新间隔 / 场上上限 |
| `BT_PACK_INT` | 10s | 血包刷新间隔（场上最多 2） |
| `BT_MAX_E` / `BT_MAX_E_C` | 250 / 100 | 能量上限：BOSS 模式 / 经典·无伤 |
| `BT_RECHARGE_E` / `BT_RECHARGE_T` | 5 / 5s | 回能触发阈值 / 回满时长 |
| `BT_WALL_E` / `BT_WALL_CD` | 5 / 10s | 放墙能量消耗 / 冷却 |
| `BT_BOSS_INT` / `BT_BOSS_INT_BS` | 300s / 60s | 经典 / BOSS 模式刷新间隔 |
| BOSS 血量 | 500\~1500 | 可见，`hpMax` 归一化 |

### 12.5 记录与统计
- 历史 entry：`mode:'battle'`，`score = 坚持时长（秒）`，含 `duration`、`kills`、`survived`（`false`=阵亡 / `true`=主动退出）、`levelName/formula = '点之对战'`。
- 主动退出（`btExit(true)`）与阵亡（`btGameOver`）都保存；历史行显示「阵亡 / 主动退出」徽标。
- 历史统计 chip「对战最长」= 所有 `mode==='battle'` 记录中 `duration||score` 的最大值，`fmtDur` 显示 `m:ss`；其余统计（平均分/最高分/满分次数）仍只统计原函数游戏记录。

## 13. 24点挑战模式（Make 24）

在「设置」左侧的「24点挑战」标签页，与「点之描函」「点之趋安」「点之对战」并列，为品牌「函迹 · FuncTrace」下的第四个、也是唯一一个**卡牌益智**子游戏。纯前端实现，无服务端依赖（两版同构）。

### 13.1 玩法
- 开局发 **4 张牌**：点数取自 A=1、2~10、J=11、Q=12、K=13（随机附 ♠♥♦♣ 花色仅装饰），显示为扑克样式卡片。
- **点选两张牌**（高亮）再点运算符 **＋ － × ÷** 合并成一张新牌；**√ 与 ! 是单目运算，只需选中一张牌**。
- 每合并不产生新牌数变化（双目 4→3→2→1，单目只改变牌值），**牌数剩 1 且值 = 24（容差 1e-6）即解出胜利**；「撤销」回退上一步，「重新发牌」换一局。
- 计时从发牌开始；胜利/退出都写入历史（`mode:'g24'`）。

### 13.2 运算与「分数/根式保留形式」
- 每张牌携带 `{val, expr}`：`val` 为浮点数值（参与运算与胜负判定），`expr` 为显示用的表达式字符串。
- 双目结果 `expr` 形如 `(a + b)`、`(a − b)`、`(a × b)`、`(a ÷ b)`——**除法保留分数形式**（如 `(7 ÷ 5)`，不化简为小数）。
- **√**：`√(expr)`（根式保留，如 `√(9)`、`√(2)`）；负数不可开方。
- **!**：`(expr!)`，仅限非负整数且 `val ≤ 10`（如 `(4!) = 24`）。
- 合并后的表达式牌继续参与运算时逐层嵌套（如 `((7 ÷ 5) + 3)`），最终胜利弹窗展示完整算式。

### 13.3 保证有解（发牌校验）
- 发牌前用**回溯求解**（`g24CanMake`）：对当前数字集枚举两两组合 + `+ − × ÷`（含 `a−b`/`b−a`/`a÷b`/`b÷a`）递归，命中 `|result−24| < 1e-6` 即判定可解；随机发牌最多尝试 300 次，兜底 `[3,3,8,8]`（`(3 − 8÷3) × 8 = 24`）。
- 可解性校验仅用四则运算（√ 与 ! 是玩家的捷径，不影响保证有解）。

### 13.4 模式与记录
- 两种模式卡片：**标准**（四则 + √ + !）/ **纯四则**（仅 + − × ÷，隐藏 √ 与 ! 按钮），均保证有解。
- 历史 entry：`mode:'g24'`，`score = duration（解出用时秒数）`，含 `solved`（解出/未解出）、`steps`（步数）、`cards`（牌面）、`expr`（解出的完整算式）；未解出退出同样保存。
- 统计 chip「24点最佳」= 所有 `solved=true` 记录中 `duration` 的最小值（最快解出），无解出记录时显示 `—`。
